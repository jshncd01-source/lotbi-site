ACCOUNT DELETION

LOTBI 계정 삭제 안내

LOTBI 계정 삭제는 Account Web의 공식 삭제 요청 절차를 통해 진행합니다. 공개 사이트에서는 계정 정보나 삭제 요청을 직접 수집하지 않습니다.

계정 삭제 요청 시작

로그인한 뒤 LOTBI Account의 계정 삭제 요청 영역에서 현재 계정 핸들을 다시 입력하고 명시적으로 삭제 요청에 동의해 제출합니다.

LOTBI Account에서 삭제 요청

처리 절차

  1. LOTBI Account에 로그인합니다.
  2. 계정 삭제 요청 영역에서 현재 계정 핸들을 다시 입력합니다.
  3. 삭제 요청 확인 항목에 동의한 뒤 요청을 제출합니다.
  4. 요청이 접수되면 LOTBI Core가 반환한 공식 receipt를 기준으로 요청 상태와 purge 예정 시점 등 처리 정보를 확인합니다.

삭제와 보존에 관한 안내

계정 삭제 요청이 접수되면 계정 접근 권한과 데이터 처리는 LOTBI Core의 공식 정책과 receipt를 기준으로 처리됩니다. 공개 사이트는 즉시 hard delete를 보장하거나 별도의 삭제 일정을 임의로 표시하지 않습니다.

법령상 보존 의무, 분쟁 대응 또는 거래 기록 보존 등 별도의 근거가 있는 정보는 해당 근거와 보존기간에 따라 처리될 수 있으며, 정식 서비스의 개인정보처리방침에 구체적으로 반영됩니다.

로그인 또는 삭제 요청에 문제가 있는 경우

계정 접근이 어렵거나 삭제 요청 절차를 진행할 수 없는 경우 developer@lotbiai.com으로 문의해 주세요. 보안을 위해 본인 확인이 필요한 경우 추가 확인을 요청할 수 있습니다.
